# Gradio UI Example Images

This directory contains procedurally generated synthetic leaf images used as Gradio UI example inputs.

- `sample_leaf_01.png`: Synthetic green wheat leaf with a single moderate Septoria lesion spot.
- `sample_leaf_02.png`: Synthetic green wheat leaf with multiple rust lesion spots.
